SQL LAB 0.3.3 · 检查更新与安装重试修复。

修复 0.3.2 中安装阶段异步失败后重试可能被前端锁住的问题，并补充保存与重试回归检查。

- 新增顶部“检查更新”和 Windows“帮助 → 检查更新”。更高的正式版本自动下载、校验、保存工作台并重启安装；显示进度和失败原因。
- 不自动降级、不使用预发布版本；保存失败不重启。
- 网页同时检查 GitHub 和本站版本：已部署新版时保存并重新加载，尚未部署时提示管理员处理。
- 提供已配置 `/sql-lab/` 的网页压缩包及部署脚本，修复帮助报告链接和 manifest 子目录路径。
- 发布流程保留旧版本，并在最终核验 EXE 元数据后重新生成更新哈希。27 道练习和原数据格式保持兼容。

0.3.1 及以前需先手动安装一次 0.3.3，之后才具备应用内更新功能。安装包尚未使用发布者数字证书；系统权限提示需用户处理。

下载 `SQL-Lab-Setup-0.3.3.exe`；服务器部署使用 `SQL-Lab-Web-0.3.3.zip`。`SHA256SUMS.txt`、`latest.yml`、`desktop-smoke.json` 和 `metadata-audit.json` 分别提供文件校验、更新元数据、安装检查和可选身份元数据检查记录。

这是基础学习模拟器。真实 MySQL 8.4 对照、iPhone Safari 完整实机及不同公开版本间自动替换重启的完整实机验证仍未完成。更新下载检查使用本地测试源与模拟旧客户端版本，具体结果以报告为准。
