SQL LAB 0.4.0 · 示例表、预期结果与手机练习改进。

- 45 道统一练习，保留原有 27 题的题号、目标、参考答案、判题规则和进度格式。
- 每题展示独立示例表及预期输出；修改数据与表结构题展示操作后的数据和列定义。示例由批改使用的同一数据副本在 Worker 中计算。
- 新增稳定分页、条件筛选、连接语义、客户收款分析、NULL 对照、批量写入与预算表设计练习，支持知识点和难度筛选。
- 手机增加“题目”区域，处理可视视口缩小及上移，重新测量编辑器，提供键盘上方执行与收起按钮；执行后收起键盘查看结果。
- IndexedDB、备份格式和桌面存储来源保持兼容，保留既有检查更新功能。

下载 SQL-Lab-Setup-0.4.0.exe；服务器部署使用 SQL-Lab-Web-0.4.0.zip，已配置 /sql-lab/ 子路径。SHA256SUMS.txt 提供文件校验，latest.yml 供应用内更新，desktop-smoke.json 与 metadata-audit.json 是本版本发布流程的检查记录。

0.3.2 起可在应用内点击“检查更新”；更早版本需手动安装一次。安装包尚未使用发布者数字证书。真实 MySQL 8.4 对照和 iPhone Safari 虚拟键盘完整实机验收仍未完成，手机修复已通过自动化与 Chromium 视口模拟验证。
