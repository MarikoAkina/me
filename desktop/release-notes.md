SQL LAB Windows 桌面版，适用于 Windows 10 / 11 x64。

- 安装后即可离线使用，不需要 MySQL 服务器、Node.js 或账号。
- 与网页版使用同一套 SQL 引擎、财务示例和 15 道独立练习。
- 数据保存在电脑本地，退出再打开可继续练习。
- 用“数据与备份”中的完整 JSON 备份在网页版和桌面版之间迁移。

下载 `SQL-Lab-Setup-0.2.1.exe` 并安装。`SHA256SUMS.txt` 用于核验文件完整性。此安装包没有 Authenticode 发布者证书，Windows 可能显示“未知发布者”。

SQL 支持范围和与 MySQL 的兼容差异见项目 README。第三方软件许可证保留在安装目录。
