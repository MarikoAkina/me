# 0.3.1 界面与练习说明

此版本按验收意见恢复 0.3.0 的整体前端，仅调整“工作台／学习练习”切换栏，并保留练习分类合并和可选开发署名清理。本次验收通过后同步至正式站点与 GitHub；0.3.0 备份和旧发布文件继续保留。

## 界面恢复范围

页头、品牌图标、说明文字、灰蓝配色、字体、间距、卡片、数据库树、编辑器、Result Grid、学习面板和手机布局均恢复原版。主入口、SQL 编辑器组件、弹窗组件与 HTML 标题也恢复原文件。

截图所示切换栏改用统一的终端与书本细线图标，取消鼓起的阴影，以细边框和浅蓝选中背景区分状态；按钮可点击高度为 44px。手机端沿用原版的纯文字显示，避免图标挤占空间。切换仍使用原有 Tabs，保留文字名称、键盘操作和选中状态。

样式差异逐条核对后，除切换栏和移除已不用的练习范围筛选样式外，与原版一致。详细记录见 [恢复范围核验](../public/frontend-rollback-checks.json)。

## 统一练习列表

合并前后均为 **27 个唯一题目，ID 为 1–27**。取消“全部练习／本轮新增”的范围切换，不重复添加题目。知识点类别、学习顺序、题目目标、答案、提示、判题规则和独立数据全部保留。手机学习模式的选题入口显示为“练习”。

SQL 引擎、种子数据、Worker、IndexedDB 和备份格式没有修改，无需数据迁移。完整定义核对见 [题目一致性记录](../public/lesson-integrity.json)。原正式站点地址和数据格式不变，已有记录可继续使用；从独立验收站点迁移时可导出、恢复完整 JSON 备份。

## 本轮实际验证

2026 年 10 月 24 日重新运行 **149 项测试，全部通过**：核心 81、扩展 35、存储 8、DOM 集成 18、桌面协议 7。生产构建和静态运行包自检通过。既有备份仍保留，恢复方法见交付附带的恢复说明。

在 Chromium 中实际检查了 375、390、430、768、1280px 的 iframe 视口，没有页面整体横向溢出。实际操作包括：工作台与学习模式切换、统一列表选题、第 23 题 SQL 输入与执行批改、显示两个正确月份金额、表结构展开、默认折叠答案、全屏编辑及退出、刷新后草稿和 1/27 进度恢复、HTTP 下的手动复制降级。结果与布局数据见 [本轮验收记录](../public/ui-review-checks.json)。

## 署名与产物检查

根目录和桌面包的可选 author 字段删除；打包配置中的可选版权资源字段留空，没有用虚构名称替代。检查本次源码、HTML、包配置、图片元数据及最终压缩包；HTML 无 author / generator 元标签，截图无 EXIF 作者、软件或注释字段，ZIP 无额外注释。

保留 MIT 真实版权声明、第三方许可证、依赖信息、教学示例邮箱、有效 GitHub 与站点网址，以及发布流程中用于检查可执行文件署名的关键词。历史提交、账号与托管平台记录、旧发布文件没有改写。旧 0.3.0 安装包继续保留；0.3.1 安装包由 Windows 发布流程构建、安装检查及读取最终元数据，结果以发布报告为准。
