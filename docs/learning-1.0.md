# 1.0.0 手机同屏练习

手机选择题目后直接进入编辑器。上方“题目要求／本次结果”切换参考内容，下方保留 SQL。可拖动分隔条、移动滑杆或用分隔条上的上下方向键调整高度，比例随工作台保存并随 JSON 备份迁移。面板在键盘弹出时仍显示目标，长题目可在面板内部滚动。

执行并批改后，上方面板自动显示本次反馈和查询结果，点击数据可复制；下一题入口仅在通过后出现。错误可直接定位编辑器；复杂结果仍可展开到原有完整结果区。桌面分栏、历史与工作台功能保留。

移除了 CodeMirror 额外绘制的选区层，使用原生选区，避免两套高亮叠加；主动补全仍可由 Ctrl+Space 调用。系统自身的选择菜单由浏览器与 iOS 绘制，不能宣称完全控制其图层。

45 题增加要求拆解、步骤、易错点、解释与自查；题目 ID、参考答案和判题规则不变，旧进度兼容。内容由本地题库提供，不依赖 AI API。

测试与构建结果以本版本检查报告为准。真实 iPhone Safari 选区菜单、中文输入法与横竖屏实机仍待回归。更新前导出完整 JSON。若服务器自动更新器已安装，可等待定时检查或执行 sudo systemctl start sql-lab-web-update.service；未安装时按更新指南部署新版网页 ZIP。
