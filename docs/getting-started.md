## 打开工作台

Windows 用户可在 [发布页](https://github.com/MarikoAkina/sql-lab/releases/latest)下载安装程序。当前版本为 1.0.2，适用于 Windows 10 / 11 x64；安装后即可离线使用，无需安装 MySQL、Node.js 或注册账号。

手机可直接打开 [公开体验网页](https://akinaly.top/sql-lab/)，无需注册应用账号。也可按 [开发与部署指南](development.md)运行自己的网页实例。

首次打开会创建示例数据库，并选择 `finance_lab`。以后打开会读取当前浏览器保存的工作台，不会重新覆盖示例数据。当前产品是 [MySQL 基础学习模拟器](sql-compatibility.md)，不提供真实 MySQL 服务器连接。

## 写出第一条 SELECT

在编辑器输入：

```sql
SELECT * FROM customers;
```

点击 **执行 SQL**，在 Result Grid 中查看初始示例的 5 位客户。`SELECT` 表示查询，`*` 表示全部列，`FROM customers` 指定查询客户表。

接着输入：

```sql
SELECT name, city
FROM customers
WHERE city = '武汉';
```

这次只返回姓名与城市两列，初始数据中符合条件的有 3 行。中文字符串放在英文单引号里，语句以英文分号结束。如果你已经修改了客户表，结果行数会随实际数据变化。

再试一次费用汇总：

```sql
SELECT category, SUM(amount) AS total
FROM expenses
GROUP BY category
ORDER BY total DESC;
```

`SUM` 把金额相加，`GROUP BY` 按费用类别分组，`AS total` 为结果列起名，`ORDER BY` 把合计从高到低排列。

## 工作台怎么用

| 区域 | 可以完成的操作 |
| --- | --- |
| 数据库 / Schemas | 展开数据库、表与字段；查看字段类型和主键；选择“查看数据”或“插入 SELECT” |
| SQL 编辑器 | 新建或切换脚本标签，输入 SQL、格式化、保存脚本，执行选中内容、当前语句或全部语句 |
| 结果 / Result Grid | 切换多个查询结果，查看行数和 NULL，分页、复制与导出 CSV |
| 执行日志 | 查看每条 SQL 的成功状态、影响行数、执行时间，以及失败位置和中文解释 |
| 历史 | 查看已执行的语句，并重新放入编辑器 |
| 数据与备份 | 导出完整 JSON、恢复备份、导入 SQL、恢复示例库或清空数据 |

电脑可以用 **Ctrl / ⌘ + Enter** 执行光标所在语句。连续执行多条语句时遇错停止，已经成功执行的修改会保留；SQL 文件导入失败则整份回退。

工作台中的 INSERT、UPDATE、DELETE 和结构修改会改变并保存数据。学习练习的写入操作在独立副本中进行，适合先熟悉修改范围。

## 在手机上输入和查看结果

1. 用底部 **数据库／编辑器／结果／历史** 切换区域；学习模式下使用 **练习／题目／编辑器／结果／历史**：练习用于选题，题目用于查看示例表与预期结果。
2. 需要更多输入空间时打开全屏编辑模式。
3. 用 SQL 辅助栏插入单引号、反引号、括号、逗号、分号、星号和常见关键字。
4. 键盘弹出时，执行与“收起键盘”显示在键盘上方。输入完成后点击执行；执行会收起键盘并打开结果。
5. 轻点结果单元格，再点击 **复制单元格**；也可复制整张结果表或导出 CSV。

宽表格可在结果区域内左右滚动。每页显示 100 行，CSV 导出包含当前结果集的全部行。复制权限不可用时，程序会提供可手动选择并复制的文本。

编辑器配置为关闭自动纠正、自动大写与拼写检查。手机系统键盘的智能标点受系统设置影响，输入 SQL 时请检查引号和符号是否正确。虚拟键盘、触控选区和复制行为的实机验收状态见 [测试文档](testing.md)。

## 按顺序完成练习

切换到 **学习练习**，阅读目标、示例数据、表结构与预期结果，点“编写 SQL”，输入自己的 SQL，再点击 **执行并批改**。需要帮助时逐步展开提示，参考答案默认折叠。

| 练习 | 学习内容 |
| --- | --- |
| 1–2 | 全表查询、选择需要的列 |
| 3–6 | 中文条件、金额区间、逻辑组合、排序、LIMIT、去重与空值 |
| 7–9 | COUNT 与 NULL、费用汇总、GROUP BY 与 HAVING |
| 10–11 | 保留未匹配记录的 LEFT JOIN、平均金额子查询 |
| 12–14 | 插入客户、修改指定订单、删除指定费用 |
| 15 | 设计包含主键、非空字段、金额与日期的预算表 |
| 16–21 | CASE 分类、IF 与空值、中文截取、清理和替换 |
| 22–24 | 日期提取、按月汇总与日期差 |
| 25–27 | 条件聚合、预算取整和综合费用分析 |
| 28–33 | IN、LIKE、逻辑括号、稳定分页、含税金额与分组筛选 |
| 34–39 | INNER JOIN、反向匹配、ON 与 WHERE、付款客户、收款汇总与 NULL 对照 |
| 40–45 | 多行插入与默认值、批量修改、条件删除、修改表与收款计划设计 |

目前共 45 题，全部显示在同一列表中。可按知识点和难度筛选，所有题目保持唯一编号。数据修改题展示操作后的完整数据，结构题展示修改后的列定义。第 23、27 题含独立的 10 月附加记录，便于检查月份筛选；工作台数据不会因此改变。新函数示例见 [首轮扩展指南](expansion-1.md)。

查询批改比较实际结果，接受得到正确结果的不同写法。除要求排序的题目外，不因行顺序不同而判错；重复行、列顺序和 NULL 仍参与比较，列别名不限。

写入和建表练习检查独立数据的最终状态，可以重新开始，不影响工作台数据库。通过记录和练习草稿会自动保存。

## 添加到手机桌面

- iPhone Safari：打开你的网页实例 → **分享** → **添加到主屏幕**。
- 安卓 Chrome：打开网页实例 → 浏览器菜单 → **添加到主屏幕**；具体名称以浏览器为准。

站点提供图标、主题色和独立显示配置。添加到主屏幕不代表网页已具备完整离线缓存；Windows 安装版可离线使用。Safari 与主屏幕打开方式可能使用不同存储空间，迁移前请 [导出完整备份](data-and-backup.md)。

## 1.0 手机上下同屏做题

手机选题后直接进入编辑器，上方题目面板保留目标。切换“本次结果”查看批改反馈，草稿保留在下方；点“示例与讲解”阅读表数据和详细步骤。拖动面板底部右侧的上下箭头手柄调整比例，布局随工作台保存。键盘弹出时目标仍可滚动阅读，执行按钮位于键盘上方；批改后不再强制离开编辑器。点击结果数据可复制，复杂查询可展开完整结果与日志。
