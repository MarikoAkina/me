

## Windows 安装后操作检查

Windows 工作流构建 NSIS 安装包，实际静默安装并启动程序。发布流程配置以下 10 项检查；**仅在发布报告实际记录通过时才视为完成**，见 [安装检查报告](https://github.com/MarikoAkina/sql-lab/releases/download/v0.3.1/desktop-smoke.json)。

1. 安装后的应用加载本地界面和 SQL Worker。
2. 编辑器输入与条件查询返回正确结果。
3. 打包后的 Worker 完成十进制计算。
4. 多语句执行与写入。
5. 原生剪贴板复制。
6. 下载 JSON 备份并确认包含写入数据。
7. 刷新后恢复 IndexedDB 数据与 SQL 草稿。
8. 打包后执行新 CASE、DATE_FORMAT 和 ABS 金额表达式。
9. 统一 27 题、跨月汇总批改、刷新后恢复草稿进度，并确认工作台写入仍保留。
10. 下载面板指向正确版本的安装程序。

这些是 Windows CI 环境中已安装应用的检查，单独记录，不并入 149 项。它们不等同于普通 Windows 10 / 11 实机全流程验收。发布工作流还读取安装包和主程序的 PE 版本字段，检查产品、公司、版本、注释和版权信息，将结果保存为 `metadata-audit.json`；法定及第三方许可证保留。

## 自动化检查的边界

DOM 集成使用 jsdom、真实 SQL Worker 代码与 fake-indexeddb，能验证状态和交互逻辑，但没有真实浏览器布局引擎。375、390、430、768、1280px 的检查覆盖导航状态、输入配置与响应式样式代码，不能代表 Safari 触控、虚拟键盘或像素溢出验收。

0.3.0 当时未完成网页像素检查；本轮界面副本修正开发服务器允许的预览主机后，在正式版本之外完成了上述 Chromium 实际渲染检查。

SQL 验收检查当前结构化执行器的实际结果和状态，另按 MySQL 8.4 官方文档审查新增函数语义；没有可用的 MySQL 服务器或容器，尚未完成真实 MySQL 8.4 逐条差分。测试通过不表示完整 MySQL 兼容，已知分支类型、日期和排序规则差异见 [兼容文档](sql-compatibility.md)。
