# 数据、备份与恢复

[文档目录](README.md) · [新手指南](getting-started.md) · [兼容限制](sql-compatibility.md)

## 数据保存在哪里

SQL LAB 使用 IndexedDB 自动保存数据库结构、表数据、自增状态、脚本标签和草稿、执行历史、练习草稿及完成进度。

| 使用环境 | 保存位置与迁移方式 |
| --- | --- |
| 网页版本 | 当前浏览器、当前站点来源的 IndexedDB |
| Windows 安装版 | 本机 `%APPDATA%\SQL LAB` 下的应用数据；在程序中导出 JSON 迁移 |
| 换浏览器、设备或使用网页与桌面版 | 分别保存数据；通过完整 JSON 手动迁移，不会自动同步 |

示例数据只在首次初始化时创建，刷新不会覆盖修改。关闭前确认页面已显示保存成功。保存失败时，先导出备份再刷新。多个标签页同时修改同一工作台没有合并机制，建议只在一个标签页中编辑。

无痕浏览、清除网站数据或不同的浏览器存储空间会影响原记录。应用用户数据不包含在 GitHub 仓库或安装包中。

## 选择正确的导出方式

| 操作 | 包含内容 | 适合用途 |
| --- | --- | --- |
| 完整 JSON 备份 | 数据库、数据、自增状态、脚本和练习草稿、历史、进度与主题 | 完整恢复，或在网页与 Windows 版之间迁移 |
| 数据库 SQL 导出 | 建库、建表与表数据 | 在空工作台恢复结构和数据；不包含完整自增状态、草稿、历史和进度 |
| 保存脚本 | 当前编辑器的 SQL | 保存和分享一份练习脚本 |
| 结果 CSV 导出 | 当前选中结果集的列与全部结果行 | 在表格软件中查看、分析结果 |

完整恢复优先使用 JSON。SQL 和 CSV 不是完整工作台备份。

## 导出和恢复完整备份

1. 打开 **数据与备份**，选择完整 JSON 导出，保留下载文件。
2. 在目标工作台打开同一面板，选择恢复 JSON，选中备份文件。
3. 程序先校验格式、结构、类型、约束与行数据；校验失败会给出具体错误。
4. 校验通过后，确认替换当前工作台。恢复会替换数据库、草稿、历史与学习进度。

恢复前可以先导出目标工作台的备份。JSON 文件最大为 20 MB，应来自 SQL LAB 的完整备份功能。

Windows 升级沿用原数据；卸载默认不会清除练习数据。重要进度仍应另外保存备份文件。

## 导入和导出 SQL 文件

**保存脚本**导出当前编辑器内容。数据库 SQL 导出包含所有库的结构和数据；导入到已有同名表的工作台会报错，不会自动覆盖表。

导入 `.sql` 文件时，确认后会在当前工作台执行。任一语句失败，整份脚本的数据库修改都会回退，并显示失败语句及位置。默认最多 200 KB、100 条语句；更大文件需要拆分，但每个分批文件各自回退。

在编辑器直接执行多条 SQL 的规则不同：遇错停止，保留此前成功的语句。两种方式都不会留下某条失败写入语句的部分数据。

## 恢复示例或清空工作台

| 操作 | 影响范围 |
| --- | --- |
| 恢复示例库 | 替换 `finance_lab` 和 `campus_lab`，保留其他自建数据库；不会清空所有草稿、历史与进度 |
| 清空全部数据 | 清空所有数据库、草稿、历史与进度；之后可手动恢复示例库 |

两项操作均需确认。“恢复示例库”会覆盖你对这两个示例库的修改，需要保留时请先导出备份。
