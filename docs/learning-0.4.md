# 0.4.0 练习与手机改进

## 每道题现在可以看到什么

选题后先看目标、实际示例数据和可展开的表结构，再对照预期输出编写 SQL。查询题显示预期行与列；INSERT、UPDATE、DELETE 展示操作后的完整相关表；CREATE 与 ALTER 展示目标列定义及数据。没有源表的常量题、新建表题明确说明，无占位表。

示例和预期输出在 Worker 中由 `createLessonState` 与参考 SQL 计算，使用与批改完全相同的独立副本。第 23、27 题的跨月数据，第 39 题的 NULL 对照表，第 43、44 题的预算表都只属于相应题目。它们不会改写工作台。

结果比较允许不同正确 SQL；列别名不限。要求排序的题目检查行顺序，其他题目按多重集合比较，仍核对重复行、列顺序、金额和 NULL。参考 SQL 默认折叠。

## 手机操作

学习模式底部依次为“练习／题目／编辑器／结果／历史”。“练习”选题，“题目”查看示例表与预期输出，点“编写 SQL”进入编辑器。宽表在自身区域左右滚动，不撑宽页面。

修复范围：监听 `visualViewport.resize` 与 `scroll`，同时处理高度和顶部位移；编辑器重新测量并滚动当前光标到可见区。键盘弹出时压缩无关栏，在键盘上方提供“执行并批改／收起键盘／查看题目”；执行后主动收起键盘，进入结果。辅助符号按钮保留编辑焦点；编辑字体保持 16px，不禁止用户缩放。横屏触屏设备也使用紧凑编辑布局。

## 实际验证与边界

2026-10-26，源码 `npm test` 的 190 项全部通过；包含所有 45 题参考答案、原 27 题完整定义核对、独立手算结果、修改范围、默认值、表结构、旧备份兼容、第 45 题刷新恢复、输入执行与复制流程。根路径与 `/sql-lab/` 生产构建均检查。

在真实 Chromium 页面用开发 iframe 检查 375、390、430、768、1280px；页面未横向溢出，宽结果表在自身区域滚动。查看手机题目页及平板分栏截图。模拟可视高度 300px、顶部上移 36px 时，编辑区与执行按钮可见，完成输入 SELECT、执行批改、收起模拟键盘、复制结果、再次编辑。另有自动化检查覆盖 Android 双视口缩小、键盘平移、关闭、旋转事件和缩放排除。

上述键盘检查是模拟，未连接真实 iPhone 或真实输入法；Safari 的系统工具栏、中文组合输入、横竖屏切换和不同系统版本仍需实机回归。没有真实 MySQL 8.4 差分环境，本轮未扩大 SQL 引擎的兼容声明。Windows 安装结果以本版本 Release 中的 `desktop-smoke.json` 为准；历史 0.3.2 → 0.3.3 升级报告不代表本次新版的完整跨版本验证。
