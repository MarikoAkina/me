保留当前行浅蓝背景、原生文本选区、键盘适配、同屏练习面板、45 题及进度保存。没有恢复旧 drawSelection 额外选区层，避免重新引入先前的框选图层问题。没有回滚其他前端、学习内容或执行引擎。

这是独立预览分支，未替换正式站、正式 Release 或旧安装包。原自定义补全模块暂保留用于对照，但已不接入编辑器。正式 1.0.3 的历史测试报告不作为本分支测试结果。
