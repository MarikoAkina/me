# SQL 智能补全（1.0.3）

输入关键词或名称后自动显示候选。上下方向键选择，Enter 或 Tab 填入，Escape 收起；Ctrl+Space 或编辑器下方“补全”按钮可主动唤出。手机可直接点候选项。输入字符串与注释时不弹出候选；中文输入法仍应以系统组词确认为准。

FROM/JOIN 后主要列出表与数据库；USE 后列出数据库；SELECT、WHERE、ORDER BY 等表达式位置列出当前语句引用表的字段、函数和关键词。输入 orders. 或别名 o. 可筛选对应字段。主键使用钥匙形 SVG 图标并标注“主键”，其他类型以表、列、函数和关键词图标区分。字段同时显示 INT、DECIMAL 等真实类型。建表、ALTER、DROP、切换数据库与练习后重新读取当前元数据。

两表重复字段优先提供 c.id、o.id 等限定名。基础 SELECT 子查询按括号层级隔离字段；保留 CodeMirror 的 SQL 语法树、反引号和别名解析，增加应用词法器的表引用分析。不推断派生表、CTE、复杂相关子查询或计算列别名的输出结构；补全不能替代执行校验，也不会向远程数据库或 AI API 发送 SQL。

手机候选行至少 44px，列表可滚动并限制高度；收起后继续编辑。当前行浅蓝背景、原生选区和同屏练习面板保留。真实 iPhone Safari 输入法、系统选区与触控仍需实机回归。
