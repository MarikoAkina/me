# SQL 智能补全（1.0.4）

本版采用已验收的初代 CodeMirror 原生补全。输入关键词或名称后自动显示候选，方向键选择、Enter 填入、Escape 收起，Ctrl+Space 主动唤出。手机可以直接点选候选。原生候选默认填入小写关键词，例如输入 `SEL` 并接受后得到 `select`；SQL 关键字大小写不影响执行。Tab 沿用编辑器缩进，不作为本版承诺的接受候选快捷键。

当前数据库的表名与字段名传入 MySQL 补全扩展：`FROM` 后可以选择表；输入 `orders.`，或在 `SELECT o. FROM orders AS o;` 的点号后主动唤出，查看对应字段。建表、修改结构、切换数据库或练习后，重新读取当前表与字段。字符串、注释、反引号和基础表别名交由 CodeMirror SQL 语法树处理。

候选使用初代默认图标与排序。字段旁的钥匙形图标属于 CodeMirror `property` 类型，所有字段都可能使用，**不表示真实主键**；数据库树的主键标记仍来自表约束。本版没有自定义 SVG 候选、字段类型说明或候选“主键”标签，也没有单独的手机“补全”按钮。默认字形外观取决于设备字体。

补全元数据是“表名 → 字段名数组”，不包含完整的跨库、类型或主键信息，不推断复杂派生表、CTE 或计算列别名的输出结构。MySQL 词典可能提示模拟器尚未支持的语法，能否执行以 [支持范围与兼容限制](sql-compatibility.md)和执行结果为准。SQL 不会发送到远程数据库或 AI API。

当前行浅蓝背景、原生文本选区、键盘适配与同屏练习面板保留。初代曾使用的额外选区绘制层没有恢复，以免重新引入框选图层问题。真实 iPhone Safari 的系统选区、中文输入法与触控仍需实机回归。

历史来源与验收分支见 [初代补全复现记录](original-completion-preview.md)。
