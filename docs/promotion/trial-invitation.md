# SQL LAB 首轮试用邀请

分享一个免费开源的中文 SQL 学习工具：SQL LAB。手机浏览器可以直接练习，包含客户、订单、费用与学生成绩示例，也有 Windows 离线版。

体验网址：https://mysql-foundry.marikoakina.chatgpt.site
源码与说明：https://github.com/MarikoAkina/sql-lab

欢迎零基础同学花 10 分钟试用：

1. 输入 `SELECT * FROM customers;` 并执行。
2. 试着筛选武汉的客户，再完成前三道学习练习。
3. 复制一次结果，重新编辑 SQL，并尝试导出完整备份。

可以反馈：设备与浏览器、是否能顺利输入和执行、哪一步不理解，以及讲解或按钮有什么需要改进。SQL 问题请附能复现的语句，使用虚构数据即可。

这是 MySQL 基础学习模拟器，兼容范围和实机验收状态见项目文档。数据库、草稿和进度保存在当前浏览器，不会自动跨设备同步。
